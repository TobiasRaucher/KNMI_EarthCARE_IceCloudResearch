# KNMI_EarthCARE_IceCloudResearch
Jupyter notebooks for EarthCARE satellite ice cloud research (bachelor's thesis, KNMI). Processes ATLID lidar Level-2 products (ATL_TC, AC_TC, ATL_EBD, ATL_ICE) into gridded NetCDF outputs and generates global distribution figures for occurrence, temperature, microphysics, and optical properties (2025).
